About

Free, and built to be used

KnitStack is a free, self-paced coding academy. No trial, no paywall, no ads.

How it works

  • Start with the Refresher if you're new or rusty: nine lessons from variables to polymorphism.
  • Each Lab ticket hands you a working starter project. You write the core logic and the tests tell you when it's right.
  • Explainers show one idea at a time as a diagram you can step through, with a short quiz at the end.
  • Everything runs in your browser, including the compilers. Your code never leaves your machine.

Your progress

  • Without an account, progress and drafts are saved in this browser only.
  • Sign in with email, GitHub or Google to keep your XP, finished lessons and drafts across devices.
  • We store your email, your progress and your drafts. Nothing else, and we never sell or share it.
  • You can reset your progress any time from the footer.

Languages

  • JavaScript runs natively. TypeScript is compiled by the official TypeScript compiler.
  • Python runs on Skulpt, a Python 3 interpreter written in JavaScript. It covers what the lessons need but not all of Python.
  • Java uses OpenJDK's javac and TeaVM, Go uses the real Go compiler, and C# uses Roslyn and the .NET runtime. All three are compiled to WebAssembly.
  • The first Java, Go or C# run downloads the compiler (tens of MB) and takes a few seconds. After that it's cached.

Where the facts come from

  • Explainers are checked against official documentation: MDN, kubernetes.io, docs.docker.com, git-scm.com, redis.io, postgresql.org, the Python docs and the relevant RFCs.
  • Each explainer links to its sources under "Read more".
  • Numbers marked "example" are illustrative. Real timings depend on your hardware, network and data.
  • Spotted a mistake? Open an issue on the project's GitHub.
